# WorkoutApp 🏋️‍♂️📦

Локальный программный комплекс для строгого учета и контроля параметров физических тренировок. Разработано по методологии ОТК: монолитная архитектура, предсказуемое управление ресурсами, 100% изоляция личных данных.

## 🛠️ Технологический стек
* **Язык программирования:** Python 3.12+
* **Графический интерфейс:** Tkinter (ttk)
* **База данных:** SQLite (Архитектура со стопроцентной локальной изоляцией данных, файл БД добавлен в `.gitignore`)
* **Система контроля версий:** Git / GitHub

## ⚡ Ключевые фичи и инженерные решения
* **Динамическое автодополнение:** Реализован алгоритм фильтрации названий упражнений на лету через `ttk.Combobox` и событие `<KeyRelease>`.
* **Оптимизация выборки:** Использование SQL-оператора `DISTINCT` на уровне СУБД для минимизации нагрузки на RAM.
* **Ресурсная безопасность:** Жесткий контроль соединений с БД через блоки `try-except-finally` для исключения утечек памяти и блокировок файлов.

## 📐 Архитектура проекта
* `models.py` — Бэкенд-компонент, отвечающий за прямое взаимодействие с локальной базой данных, валидацию и фильтрацию SQL-запросов.
* `ui.py` — Фронтенд-компонент, реализующий интерфейс оператора, обработку событий ввода и динамический рендеринг данных.
