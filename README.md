# 🏋️ Workout Vault (v2.4.0)

**Workout Vault** — интеллектуальная система управления тренировочным процессом, восстановления мышц и защиты суставов, построенная по принципу **API-first**.

Проект объединяет строгий backend-движок на **FastAPI + PostgreSQL 17** в Docker-контейнерах и многопользовательский десктопный интерфейс на **Tkinter** с изоляцией данных по `user_id` и персонализацией тем оформления.

---

## 🚀 Ключевые возможности (Core Features)

* **Промышленная безопасность и мультиаккаунт:**
  * JWT-аутентификация (`/auth/login`, `/auth/me`) и криптографическое хеширование паролей (`Passlib + Bcrypt`).
  * Изоляция тренировочных дневников, рекордов и визуальных тем по `user_id`.
* **«Умная корзина упражнений» (`GET /exercises/`, `POST /exercises/`):**
  * Каталог из 34+ базовых и изолирующих упражнений, структурированных по 9 мышечным плиткам (`GET /exercises/categories`) с заделом под фото- и видеоматериалы (`image_url`, `video_url`).
  * Встроенные медицинские фильтры защиты суставов: `protect_lower_back` (поясница), `protect_knees` (колени), `protect_elbows` (локти).
* **«Умный тренер» (`GET /workouts/recommend`):**
  * Алгоритм анализа истории нагрузок за последние 72 часа.
  * Автоматический расчёт времени восстановления мышечных групп и подбор безопасной программы под текущее состояние атлета.
* **Надёжность данных:**
  * Полная оркестрация в **Docker & Docker Compose** с `healthcheck` и персистентным хранилищем (`postgres_data`).
  * Скрипт автоматического резервного копирования базы данных (`backup_db.py`).

---

## 🛠️ Технологический стек

* **Backend:** Python 3.12, FastAPI, SQLAlchemy, Pydantic
* **Database:** PostgreSQL 17
* **Security:** PyJWT, Passlib (Bcrypt), Dependency Injection
* **Infrastructure:** Docker, Docker Compose
* **Desktop Client:** Python Tkinter

---

## ⚙️ Быстрый старт (Quick Start)

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com
   cd WorkoutApp
   ```

2. **Запустить инфраструктуру (PostgreSQL 17 + FastAPI):**
   ```bash
   docker-compose up -d
   ```
   *API документация Swagger доступна по адресу: `http://localhost:8000/docs`*

3. **Запустить десктопный клиент:**
   ```bash
   python main.py
   ```
